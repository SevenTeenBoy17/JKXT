## 1. 仍待解决的结构性硬伤（这是"落地"的真正障碍）

大部分不是"引擎没写"，而是**"逻辑写好了但没数据喂进去"或"界面在对教务撒谎"**：

1. **🔴 排监考第一铁律"班主任不监本班"完全失效（四层断链）**
   教师导入模板无"是否班主任/所带班级"列 → `commitTeachers` 从不写 `is_homeroom/homeroom_class_id` → 考试导入模板无班级列 → `exam_class` 表建了但全代码零 INSERT → `buildFixtureFromTask:277` 把 `classId` 写死 `null` → solver `eligible():378` 的 `classId!=null` 守卫永远短路。**默认 ON 却永不触发**，会把班主任排到自己班且系统毫无察觉。
2. **🔴 教师"上课时段 vs 监考"冲突无法感知**：无课表/timetable 任何表或字段，`overlaps()` 只比对考试场次之间，可能排出"同一时段既上课又监考"。
3. **🟠 AI 策略 DSL 静默丢弃 8/10 类规则**：`PolicyDslValidator` 接受 10 类（workload_balance/rest_gap/subject_avoid/availability_avoid/gender_mix…），但 `policyFromDsl` 只翻 2 个布尔，其余进库却不被 solver 读 → AI 页给"已生效"假象。
4. **🟠 多处"界面在撒谎"**：email/SMS 仅日志桩却默认 enabled 显示"已发送"；"运行备份"只写假成功记录不转储；fairness 面板 corridorShare/notesApplied 恒 0；安全威胁面板展示 seed 假 IP；tasks-page 强拼 8 条 MOCK 任务、硬编码计数、死筛选；占用率/津贴等派生指标写死 0/假值。
5. **🟢 导出**：xlsx 无工号列（仅姓名，重名歧义）；PDF 限前 20 行 + ISO-8859-1 无法渲染中文。
6. **🟢 工程**：2 个验收测试类仍 untracked，回归保护未入库。

## 4. 需你拍板的开放问题（直接决定 M1/M2 做法）

1. **班主任/班级绑定数据来源**：A 扩导入模板由教务一次性填（本路线默认）；B 从班级主数据 `homeroom_teacher_id` + 考场-班级映射推导。教务能稳定提供"每场考试坐哪个班"吗？
2. **教师课表**：现实能拿到吗？优先"按星期几固定课表"还是"按具体考试日临时不可用登记"？拿不到全量时，接受"仅登记冲突时段"的轻量形态吗？
3. **同年级回避**：贵校是硬性（一律不监）还是软偏好（尽量）？决定 1.1/1.4 做硬过滤还是软惩罚。
4. **通知最后一公里**：需要真实 email/SMS 外发（需采购网关+预算）还是 in-app + 导出张贴即可？暂不外发的话，接受 UI 明示"仅站内通知"吗？
5. **"运行备份"按钮定位**：UI 内触发真实 pg_dump，还是备份由运维脚本负责、UI 仅展示？
6. **主监/副监角色**：是否要求主监为资深/在编教师？要的话需补资历字段与选取规则（当前未列入 P0–P2）。
7. **上线规模**：单次大考最大约多少场×多少教师？决定 Track4 压测目标与求解时间窗策略。
8. **巡考/流动监考/收发卷分工**：本期是否需要？当前 role 仅 main/assistant，扩角色涉及 schema + 求解器较大改动。
