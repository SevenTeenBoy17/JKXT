# 前端与百炼模型升级验收契约

## 范围与原则

本轮仅优化现有教务界面的可读性、真实操作和 AI 接入。保留登录历史 Logo、固定视口、现有任务/资源/审批业务与数据，不实施数据库迁移，不自动开启云端付费服务。

模型接入使用用户提供的北京百炼工作空间端点；密钥仅服务端环境注入，不进入源码、浏览器、日志、报告。旧网关不能复用新密钥。模型目录不等于可调用；每个模型分别记录真实请求、最终输出、错误分类和验证时间。OCR/翻译/GUI 与策略解析能力分开，不以文本冒烟替代专用能力验收。

## 原子任务与先验检查

1. AI：端点信任、完整密钥脱敏、80 个模型目录、能力校验、失败不伪装成功；新增回归测试后修复；逐项使用合成内容真实测试。
2. 任务：行编辑必须打开选中任务；导出生成真实文件；失败/空/加载分离；详情不能伪造津贴/审计日志。
3. 求解：缺失公平性/AI 字段不得使用示例数据补齐；AI 页面真实选择任务与校验数据，不偷偷创建示例任务。
4. 超管：设置受控保存/回读/取消；无后端能力的字段明确只读；审计导出真实内容；不承诺未执行操作。
5. 排版：中文正文与操作 14px、辅助 12–13px、模块标题 16px、页标题 24px；中文不滥用等宽字体；保留现有语义颜色和表格密度，修复暗色固定背景。
6. 验收：JSX 编译、功能回归、AI 单元/接口、每模型调用矩阵、登录后视觉/键盘/响应式检查及独立精确差异评审。失败/不可访问项目保持未通过。

## 参考与边界

- Ant Design 中文字体规范：https://ant.design/docs/spec/font-cn/ （14/22 正文、少量字号、系统字体、数值等宽）。

- 旧后端文档中 Node 主栈、生产 localStorage token、失败 mock 回退已被后续 Java/auth 与本轮真实结果要求取代。大型排程/迁移等未改动域按现有基线保留；上下文阅读按 AI/界面/API 相关章节限定。
