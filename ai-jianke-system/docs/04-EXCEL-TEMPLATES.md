# 04 — Excel 三张导入模板规格

> 三张表是系统**唯一约定的数据入口契约**。前后端 + AI prompt 全部依赖这套列定义。**修改列必须改本文档 + 同步迁移老数据**。

## 1. 教师安排示例表格 `01-教师安排示例表格.xlsx`

> 已有原始样本（26 名高一教师），下面是规范化定义。

| 列序 | 列名 | 类型 | 必填 | 校验 | 示例 |
|---|---|---|---|---|---|
| A | 教师编号 | text | ✅ | unique，正则 `[A-Z0-9]{2,10}` | X1 |
| B | 教师姓名 | text | ✅ | 1-20 字符 | 教师1 / 张老师 |
| C | 任教年级 | text | ✅ | 枚举：高一年级 / 高二年级 / 高三年级 / 初一年级 / ... | 高一年级 |
| D | 任教科目 | text | ✅ | 枚举：数学 / 语文 / 英语 / 物理 / 化学 / 生物 / 政治 / 历史 / 地理 / 体育 / 美术 / 音乐 / 计算机 / 信息技术 / 其他 | 数学 |
| E | 班主任 | text | ⚪ | "是" / 空 → 转 bool | 是 |
| F | 主监考 | text | ⚪ | "是" / 空 | 是 |
| G | 性别 | text | ⚪ | 男 / 女 / 空（U）；**AI 策略 S5 / 后续策略需要** | 男 |
| H | 年龄 | int | ⚪ | 22-70；**AI 策略 S5 需要**（默认空时 S5 不生效）| 45 |
| I | 跨年级授课 | text | ⚪ | 逗号分隔年级，如 "7,8"；**S6 需要** | 7,8 |
| J | 备注 | text | ⚪ | 自由文本，进入 extras.notes | 当天有延迟课 |

**示例数据**（前 3 行）：
| X1 | 王老师 | 高一年级 | 数学 |   | 是 | 男 | 45 |   | |
| X2 | 李老师 | 高一年级 | 数学 |   |   | 女 | 32 |   | |
| X3 | 张老师 | 高一年级 | 英语 | 是 |   | 女 | 50 |   | 班级有延迟课 |

**校验规则**：
- 教师编号在本单位内 unique
- 任教年级 + 任教科目均枚举校验，其他值高亮红色
- 班主任 / 主监考 接受："是"、"Y"、"yes"、"true"、空、"否"
- 性别接受："男"、"女"、"M"、"F"、空
- 列顺序不可改；多 / 少列报错

## 4. 跨表一致性校验（导入时）

1. **02 表的考场编号** 在 **03 表的"考场编号列表"** 中必须全部存在
2. **03 表的考试年级** 在 **01 表的任教年级** 中必须有教师能监考
3. **03 表的总场次 × 每场监考人数** 必须 ≤ **01 表的教师总数 × 学期可监考次数上限**
4. 任何 row 校验失败 → 表格行号 + 列名 + 期望/实际值 都要返回给前端高亮

## 6. 模板文件版本控制

- 每张表 cell A1 上方留 1 行注释：`# Template v1.0 — DO NOT MODIFY THIS LINE`
- 后端解析时检查 token，版本不符提示用户下载最新模板
- 模板下载入口：UI 每个上传卡片旁有"下载模板"按钮，链接到 `/templates/0X-*.xlsx`
