# 01 — 产品需求 + UI 规格（PRD + UX Spec）

## 1. 角色与权限

| 角色 | 账号 | 权限 |
|---|---|---|
| **超级管理员** | `superadmin` / `Super001`（默认，首次登录强制改密）| 注册普管账号 + 分配所属单位 + 系统级配置（学年覆盖、AI 模型切换、计费）|
| **普通管理员**（校级）| 由超管创建 | 本单位的 10 大功能模块（排监考、修改、统计、人员、考场、班级科目、历史、信息设置）|
| *(预留)* 教师查询 | 后续 v2 增加 | 只查自己的安排 |

**登录页**：单一入口 → 系统根据账号判断角色，自动跳到对应首页。

## 2. 左侧导航（普管首页 10 项）

按用户原文顺序：

1. **一键排监考**
2. **个性化策略 AI 监考**
3. **修改监考安排**
4. **任务总览**（柱状图）
5. **监考次数统计**（柱状图）
6. **监考人员管理**
7. **考场管理**
8. **班级科目管理**
9. **历史统计**（饼图 + 折线图）
10. **信息设置**（单位修改 / 个人信息 / 学年覆盖）

**交互细节**：
- 点击左侧按钮**界面不切换**，仅高亮当前选中（橙色边 / 主色填充）
- 中间区域内容按右下区分（与原 PC 软件一致）
- 顶部全宽 header：单位名 / 当前学年学期 / 用户头像下拉

## 3. 功能详尽规格

### 3.1 一键排监考（核心 P0）

**输入**：三张 Excel
- 教师安排表（必填，[04-EXCEL-TEMPLATES.md](04-EXCEL-TEMPLATES.md) §1）
- 考场信息表（必填，§2）
- 考试安排表（必填，§3）

**界面**：
- 中间显示当前学年学期 + 三个上传卡片（拖拽 / 点击上传）
- 每张表上传后即时校验（行数、必填、类型），失败红色标记 + 提示
- 三表全部 green 后"开始排考"按钮可点
- 排考中 → 进度条 + 已完成场次 / 总场次

**输出**：
- 总表 + 3 张分表（每个考场 / 每个时段 / 每个教师视角）
- 每张表下方"下载 .xlsx" + "AI 总结" 折叠面板
- AI 总结自动生成：本次排考遵循了哪些约束、有什么妥协、推荐校长关注事项

**算法回退**：
- AI 给主方案 → CSP 求解器（OR-Tools）二次验证可行性 → 不可行回滚 AI 重排（最多 3 次）→ 最终人工兜底界面

### 3.2 个性化策略 AI 监考（核心 P0 — 差异化）

**6 预设策略**（可勾选）：
| # | 策略 | 参数 |
|---|---|---|
| S1 | 每个教师监考时长一致 | — |
| S2 | 班主任在 5 科考试中最多监考 2 科 | 阈值可改 |
| S3 | 班主任监考次数 < 学科教师 | — |
| S4 | 当天有延迟课的教师优先安排早场（< 15:00）| — |
| S5 | 年龄 > N 岁优先楼道监考（非教室）| N 可改（默认 50）|
| S6 | 跨年级授课教师优先高年级监考 | 例：教 7&8 → 优先 8 |

**自然语言策略输入框**：
- 多行文本（最多 500 字）
- 示例 placeholder："女教师优先非高三场次；体育组当天有比赛的免排"
- AI 大模型把自然语言 → 内部约束 DSL（见 [03-AI-WORKFLOW.md](03-AI-WORKFLOW.md) §3）

**工作流**：
1. 上传教师表（仅一张，因策略主导即可）
2. 勾选预设 + 输入自然语言
3. "AI 智能排考"按钮 → 调用大模型
4. 显示中间推理过程（透明、可信赖）
5. 输出 Excel + 下载 + 可"重新生成"

### 3.3 修改监考安排

- 加载最新排考结果
- 表格编辑模式（拖拽教师 / 改时段 / 改考场）
- 每次改动触发约束实时校验（违反高亮）
- 保存 → 写入新版本（保留历史，支持回滚）

### 3.4 任务总览（柱状图）

- 当前学期总考试 / 总场次 / 总教师 / 已分配 / 待分配
- X 轴：日期；Y 轴：场次数；按已分配 / 未分配分色

### 3.5 监考次数统计（柱状图）

- X 轴：教师；Y 轴：监考次数
- 支持按年级 / 科目筛选
- 高亮明显高 / 低于平均的教师

### 3.6 监考人员管理

- 列表（CRUD）：教师所有字段
- 批量从 Excel 导入 / 导出
- 字段校验：教师编号唯一、年龄数值、性别枚举

### 3.7 考场管理

- 列表（CRUD）：考场号、所在楼栋、楼层、容量、是否楼道、备注
- 支持批量

### 3.8 班级科目管理

- 班级：年级 / 班号 / 班主任 / 人数
- 科目：年级 / 科目名 / 关联教师

### 3.9 历史统计（饼图 + 折线图）

- **饼图**：教师监考次数分布（公平度指标，标准差越小越好）
- **折线图**：按学期/学年的总场次、参与教师数趋势
- 支持导出 PNG / PDF

### 3.10 信息设置

- 单位信息（学校名 / 地址 / Logo）
- 个人信息（用户名 / 邮箱 / 改密）
- **学年学期覆盖**（详见 §4 自动算法 + 覆盖）
- AI 模型切换（仅超管：Claude / GPT / Qwen / DeepSeek）

## 4. 学年学期自动算法

- 系统统一通过 NTP / 公共时间 API 获取当前日期
- 规则：
  - **3 月 1 日 ≤ today < 7 月 16 日** → "今年-1 至 今年 学年 第二学期"（例：2026/4/22 → 2025-2026 第二学期）
  - **其他时间** → "今年 至 今年+1 学年 第一学期"
- **管理员可手动覆盖**：信息设置 → 学年信息（覆盖后所有显示同步更新）

## 5. UI 设计语言

- **风格**：教务系统专业、清爽、信息密度适中（参考 `interface-design` + `ckm-ui-styling`）
- **主色**：教育蓝 #2563eb；强调色 #f59e0b（橙）；成功 #10b981；危险 #ef4444
- **字体**：思源黑体 / 苹方（中文）+ Geist（英文数字）
- **布局**：左固定 240px sidebar + 顶部 64px header + 主区域响应式
- **图表库**：Recharts（响应式 SVG）
- **暗黑模式**：v1.1 加（不在 v1.0 范围）

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| **并发** | 单校 50 同时在线管理员，AI 排考队列 5 并发 |
| **响应** | 普通页面 < 1s；AI 排考 < 60s（300 教师 8 场考试规模）|
| **可用** | SaaS 99.5% 月可用；私有化看客户基础设施 |
| **安全** | bcrypt 12 轮密码、JWT 7 天、HTTPS only、CSRF token、SQL 参数化、敏感数据 AES-256-CBC at-rest |
| **合规** | 教育数据本地化（中国大陆服务器），出口加密；GDPR 友好（v1.2）|
| **国际化** | i18n 框架预留，v1.0 中文 only |

## 7. 验收 / 验证要点

- 6 条预设策略每条 1 个测试用例 + 边界用例（参考 [05](05-IMPLEMENTATION-PLAN.md) §测试矩阵）
- 3 张 Excel 模板自动校验：列错位、缺失、类型异常都要友好报错
- AI 排考稳定性：相同输入 + 相同 strategy 应"接近一致"（≤ 5% 教师位置差异）
- 全流程 e2e 测试：登录 → 上传 → 排考 → 下载（Playwright）
